Admin dashboard

Manage venues, categories and events. Customers search these on the public site.

Venues — Add or remove venues → Categories — Add or remove categories → Events — Publish events for search →

Quick tips

  1. Create a venue first (name, address, capacity).
  2. Create a category (e.g. Music, Workshop).
  3. Create an event linked to that venue + category.
  4. Customers can then search and filter on the public Events page.
